OpenPorts Lab Setup Bot — Privacy Policy

Last updated: February 2026

1. Scope

This policy applies to the OpenPorts Lab Setup Bot application and explains what data it may interact with while configuring a Discord server.

2. Data handled by the bot

To perform server setup, the bot interacts with Discord server resources that are already visible to it through its bot token and the permissions granted by the server owner or administrator.

This may include:

  • Server and channel names
  • Existing roles and role names
  • Basic server configuration needed to create or reuse categories, channels, and roles

The bot sends starter messages to selected channels during setup.

3. What the bot does not collect

This bot is designed as a one-time setup utility. It is not intended to:

  • Read, store, or republish user messages outside of the setup process
  • Collect personal information from server members
  • Track users across servers or across sessions
  • Build profiles of individual Discord users

4. Authentication and token handling

The bot authenticates using a Discord bot token set by the operator. The token should be stored securely and never committed to source control or shared publicly.

The maintainers do not provide a hosted service that receives or stores your bot token. Any handling of the token is limited to the operator’s own environment when running the bot.

5. Data retention

The bot does not maintain its own user database for this setup workflow.

Discord remains responsible for data stored within Discord’s platform under Discord’s own terms and privacy practices.

6. Third-party integrations

After setup, server administrators may choose to add other integrations, such as GitHub notifications. Those integrations are separate services with their own privacy practices. This policy does not cover services added by server administrators after setup.

7. Children’s privacy

Discord servers may include users under the age of 18. Server owners and administrators are responsible for complying with applicable laws and Discord’s rules regarding minors and appropriate server settings.

8. Updates

If this bot’s functionality changes in a material way, this policy will be updated to reflect the new behavior.
