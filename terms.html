OpenPorts Lab Setup Bot — Terms of Service

Last updated: February 2026

1. What this is

This page covers the OpenPorts Lab Setup Bot application and its use for configuring a Discord server for OpenPorts Lab.

The bot is intended as a one-time setup utility. It helps create server categories, channels, roles, permissions, and starter messages for a Discord community focused on open-source porting, reverse engineering, decompilation, recompilation, and related technical work.

2. Authorized use

You may use this bot only for purposes permitted by Discord’s Terms of Service and Developer Policy.

You are responsible for:

  • Inviting the bot only to servers where you have authority to configure them.
  • Using the bot token securely and never sharing it publicly.
  • Ensuring any server you configure complies with Discord rules and applicable law.

3. Bot capabilities

In a configured server, the bot may create and manage categories, text channels, voice channels, and roles, and may send initial starter messages to selected channels.

The bot is not intended to collect, store, or redistribute user messages, personal data, or server content beyond what is necessary to perform that setup.

4. No ownership transfer

Running the setup bot does not transfer ownership of a Discord server, repository, or project to the bot or to any contributor. Server ownership remains with the Discord account that owns the server.

5. User responsibility

After setup, server administrators are responsible for reviewing roles, permissions, moderation settings, and any integration they add, including GitHub notifications or other bots.
