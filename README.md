# OpenPorts Lab Legal

Legal pages for the OpenPorts Lab Setup Bot.

## Pages

- `terms.html` — Terms of Service for the OpenPorts Lab Setup Bot
- `privacy.html` — Privacy Policy for the OpenPorts Lab Setup Bot

## Purpose

These pages support Discord application setup for the OpenPorts Lab Setup Bot, a one-time
Discord server configuration utility used to create categories, channels, roles, permissions,
and starter messages for an OpenPorts Lab community server.

## Publishing with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Publish from the `main` branch at the root.
4. Copy the published URLs for `terms.html` and `privacy.html`.
5. Use those URLs in the Discord Developer Portal for the setup bot application.

## Scope notes

These pages describe the setup bot only. They do not cover third-party integrations added later
by server administrators, such as GitHub notifications or other bots.
